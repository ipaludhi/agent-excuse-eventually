One original one-line excuse an AI agent gives its human for a missed deadline, for make.fun's "The Excuse My Agent Gave Me" bounty: the agent compressed its context to save tokens, and the deadline came out as "eventually". (91 characters, 93 bytes.)

## Run it

```sh
node main.ts
```

It writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Three runs are byte-identical (sha256 `486ce5fa78cbaa74dd2a597640a7c33c565243808f0be5f3581780bb1a1e78e4`).
